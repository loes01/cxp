cxp is just a minimal file explorer that works in the terminal

cxp features
=============

+ Plugins
+ Mode
+ Configs (coming soon)

Plugins
============
Plugins are at ~/.config/cxp/plugins/  
and they are runnable through the mode feature in cxp.
To run a plugin you must type "excplugin (plugin folder name)"
If the program freezes after excplugin command, it doesn't actually freeze, you just need to press enter again.
 * Requirements for a plugin to be a plugin
    + Folder name can't have spaces in the name
    + Plugin is executed through the plugin's main.lua file  

Mode
=========
Mode feature can be accessible through the Tab key.  
Currently 2 commands are available through mode.
 * Commands
   + go (example : "go ~/.config")
   + excplugin (example is in the Plugins section)
